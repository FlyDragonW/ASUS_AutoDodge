RideReflex Demo v10 配音稿
總長 120.0 秒。字幕已按自然說話速度分句；目前影片沒有配音，保留後製空間。
順序：數位孿生 → 道路風險 → 開發機車自動避閃的動機 → 視覺模型 → Raycast → 虛警對照 → 濃霧備援 → UGen300。總長 120 秒，低於 180 秒上限。開場 13 秒為連續鏡頭，各章用 0.4 秒疊化。
相機辨識及融合已完成；UGen300 為下一階段。濃霧兩段使用相同霧效；融合段顯示實際 Raycast，模型輸入不含射線；這是 Unity 視覺霧效下的距離感測備援，不是實體雷達濃霧測試，也沒有宣稱相機能看穿濃霧。
分割畫面比較簡單影像框警戒與視覺＋Raycast；左邊 1 次警戒，右邊 0 次介入。這是單一情境示範，不代表所有純視覺系統。

【00:00:00,000–00:00:13,000】公館・汀州路三段 / GONGGUAN · TINGZHOU ROAD SEC. 3
我們把公館汀州路三段，打造成數位孿生場景。用來產生訓練影像，也能反覆測試自動避閃。像這樣突然切入的車，就可能讓騎士來不及反應。

【00:00:12,600–00:00:19,600】視線不佳・避閃關閉 / POOR VISIBILITY · AUTO OFF
如果視線不佳，又有車違停在路中間，風險就更難判斷。

【00:00:19,200–00:00:31,200】開發目標：機車自動避閃 / OUR GOAL
所以，我們想開發一套給機車使用的自動避閃系統。希望在騎士來不及反應時，協助煞車或避讓，降低碰撞風險。

【00:00:30,800–00:00:44,800】視覺模型：實際辨識結果 / ACTUAL MODEL OUTPUT
目前，我們已經訓練了第一版視覺模型。畫面上的框，就是模型辨識出的汽車和機車。但光知道有車，還不夠判斷會不會撞上。

【00:00:44,400–00:00:54,400】Raycast：模擬距離感測 / SIMULATED DISTANCE SENSING
所以我們加入 Raycast，模擬雷達的距離感測。量出障礙物的距離，並估計它的移動方向。

【00:00:54,000–00:01:06,000】辨識＋距離資訊 / PERCEPTION + GEOMETRY
辨識結果會和射線偵測到的物體配對。再交給規則控制器，決定煞車或繞開。這樣做，也能減少不必要的反應。

【00:01:05,600–00:01:18,600】虛警對照：純視覺 vs 視覺＋Raycast
像這台停在路邊的車，其實沒有擋住路徑。只看影像框的左邊，卻把它當成威脅而煞車。右邊結合 Raycast 確認能通過，就能少一次虛警。

【00:01:18,200–00:01:27,200】濃霧模擬：純視覺 / FOG · VISION ONLY
再來看剛才的濃霧情境。這次測試裡，純視覺沒有及時發出警戒，最後發生碰撞。

【00:01:26,800–00:01:38,800】濃霧模擬：視覺＋Raycast / FOG · FUSION
這時即使視覺沒有可靠的辨識結果，Raycast 仍能提供距離資訊，讓系統避開障礙。

【00:01:38,400–00:01:50,400】下一步：UGen300 部署與量測 / PLANNED DEVICE VALIDATION
目前，視覺模型還是跑在電腦 GPU 上。拿到 UGen300 後，我們會把模型部署到裝置，量測延遲、耗電，以及量化後的辨識表現。

【00:01:50,000–00:02:00,000】下一步：擴大資料與情境 / BROADER DATA & SCENARIOS
再加入更多道路、光線變化和真實影像，讓這套系統一步步適應更一般的路況。
