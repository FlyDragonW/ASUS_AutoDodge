【00:00:07,600–00:00:21,600】視覺模型：實際辨識結果 / ACTUAL MODEL OUTPUT
我們用這些影像，訓練了第一版視覺模型。畫面上的框，就是模型辨識出的汽車和機車。但光知道有車，還不夠判斷會不會撞上。

【00:00:21,200–00:00:31,200】Raycast：模擬距離感測 / SIMULATED DISTANCE SENSING
所以我們加入 Raycast，模擬雷達的距離感測。量出障礙物的距離，並估計它的移動方向。

【00:00:30,800–00:00:39,800】辨識＋距離資訊 / PERCEPTION + GEOMETRY
辨識結果會和射線偵測到的物體配對。再交給規則控制器，決定煞車或繞開。

【00:00:39,400–00:00:52,400】虛警對照：純視覺 vs 視覺＋Raycast
像這台停在路邊的車，其實沒有擋住路徑。只看影像框的左邊，卻把它當成威脅而煞車。右邊結合 Raycast 確認能通過，就能少一次虛警。

【00:00:52,000–00:00:59,000】濃霧模擬：純視覺 / FOG · VISION ONLY
濃霧則是另一個挑戰。等相機看清楚前方違停的車，可能已經來不及。

【00:00:58,600–00:01:06,600】濃霧模擬：視覺＋Raycast / FOG · FUSION
這時即使視覺沒有可靠的辨識結果，Raycast 仍能提供距離資訊，讓系統避開障礙。

【00:01:06,200–00:01:14,200】下一步：UGen300 部署與量測 / PLANNED DEVICE VALIDATION
下一步，我們會把模型部署到 UGen300，量測反應延遲、耗電，以及量化後的辨識表現。

【00:01:13,800–00:01:19,800】下一步：擴大資料與情境 / BROADER DATA & SCENARIOS
