# 固定物理時序與動態避閃

- v2 ONNX、辨識信心 0.60、350 ms 時效與相機前處理固定。
- 共用修正：ScenarioRunner 在固定物理 tick 觸發並計時；自動輸入平滑改於物理積分之前；明確順序 scenario -400 → actor -300 → radar -200 → avoidance -150 → rider 0。不改車輛制動力、操舵極限或障礙運動曲線。
- benchmark 關閉 Rigidbody interpolation，避免渲染姿態影響物理查詢。保持 timeScale=1、captureFramerate=0、50 Hz 物理；GPU 視覺仍即時非同步，整體不宣稱完全確定性。
- 保留目前控制器原始檔作 baseline；先用共用時序修正重跑基準，不能直接拿上一輪 30/8/10 歸因控制器改善。
- 時序驗證：8 個晴天動態案例，Raycast-only，在 30/90 FPS 各跑一次，核對觸發 tick、觸發姿態與結果。v2 仍載入但不提供控制證據。
- 制動校準：20/40 km/h，全煞車、保持方向，量測停止距離。不增加制動力。
- 開發：8 個既有晴天動態案例，可迭代；每次保留結果与 source SHA。
- 選定候選後：baseline/candidate 各跑同一 48 案，另外重跑 16 動態案以檢查結果重現。各跑 4 受阻保持/恢復，必須維持 0/16 陰性情境誤介入及受阻保持功能。
- 預先固定 16 個額外動態條件（30/50 km/h、不同 trigger TTA/衝突位置），選定候選後才評估，不依結果繼續調參。仍為相同世界的保留情境，非獨立道路。
- 報告碰撞與碰撞前自車速度、相對碰撞速度、通過／安全停下／超時、誤介入、觸發 tick、推論時效與延遲。未通過／退步必須保留。
